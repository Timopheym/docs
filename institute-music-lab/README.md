# The Institute — Procedural Music Lab

Interactive browser prototype for a location- and game-state-driven procedural music system.

## Run locally

Open `index.html` in a modern browser.

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FTimopheym%2Fdocs%2Ftree%2Fmaster%2Finstitute-music-lab&project-name=the-institute-music-lab&repository-name=the-institute-music-lab)

The Deploy flow can create a separate Git repository named `the-institute-music-lab` and a Vercel project for the demo.
